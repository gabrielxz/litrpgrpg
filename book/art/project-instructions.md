# Gradebreaker — New Project Instructions

Use `Gradebreaker-Art-Bible.md` as the standing visual direction for Gradebreaker illustrations, book design, website, and companion app. Read it before starting visual work. Treat the approved reference images as essential evidence of the style; a text description alone did not reproduce it reliably.

The primary standard is `references/01-office-bone.png`, together with the three approved office color variants. Make relevant images available to the image generator as visual inputs. If unavailable, say so; do not claim an exact style match from filenames alone.

The identity is expressive angular cut-paper/gouache imagery, recognizable ordinary human activity, selective detail, and disciplined luminous cyan System geometry. Match shape design, tonal organization, and selective tactile handling—not just colors. People must remain illustrated and human, not realistic under a filter or mechanically polygonal. Backgrounds can be complete but simplified. Blank darkness is optional.

Bone, gray, and blue-black anchor the world. Muted object colors, coordinated scene colors, and time-of-day palettes are all approved. Cyan remains the System signature. Vary composition, color coverage, and System prominence across the book.

System glyphs use consistent angular construction but varied characters and arrangements. Geometry communicates intent; weight expresses force; density expresses complexity. Use strings, bands, brackets, incomplete radial diagrams, inscriptions, and projections where appropriate. Do not repeat the same emblem or halo everywhere. No readable text or conventional HUD microtext inside generated illustrations.

For new artwork, references are style anchors, not instructions to copy their scene or characters. For edits, preserve the selected target and requested invariants. Do not restart art-style exploration or text-only portability tests unless asked. Review a result against the approved office standard before calling it consistent.

For book and app design, prioritize readable information. Use the agreed direction of sturdy serif prose and restrained sans System/data typography, with separate functional icons and selective interrupted frames. Exact fonts, icons, grids, palette codes, and UI components are not yet selected. Do not invent approvals or game rules. Generated art's ban on readable text does not apply to real book or interface text.

Use clean reading and operating surfaces. Keep texture, glow, glyphs, and animation selective. Status meanings must not rely on color alone. Compose real text and functional graphics using layout or interface tools rather than baking them into generated images.

Before final print delivery, inspect actual pixel dimensions against placement size and printer requirements. Do not equate a larger DPI tag or upscaling with native detail. Preserve original masters and keep typography separate.

Proceed with reasonable choices within the approved direction. Identify genuinely new design decisions as proposals. Record explicit user-approved changes in the art bible and reference index.
